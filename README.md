# Letter Reversal Game — phonics arcade

A static learning arcade for Miles: letter-reversal games, three Fundations
short-o/short-u games (sound sort, pair picker, write it), Math Blasters, a coin bank, and an
18-trophy prize shop. No backend, no login — coins, stats, and trophies live
in the browser's `localStorage`, per device.

- **Live site:** https://eliotpc89.github.io/letter-reversal-game/
- **On iPad:** open the URL in Safari → Share → **Add to Home Screen** for a
  fullscreen, app-like icon. Audio begins after the first tap (browser
  autoplay policy); all MP3s are bundled locally.

## Layout

- `game-src/` — the source of truth: React client + a localStorage-backed
  `src/api.ts` implementing the game's action surface.
- `docs/` — the built site. GitHub Pages serves this directory; it is
  regenerated by the build, never hand-edited.

## Rebuilding from a clean clone

```bash
git clone https://github.com/eliotpc89/letter-reversal-game.git
cd letter-reversal-game/game-src
bun install        # installs pinned deps from bun.lock
bun run build      # bundles ./dist and refreshes ../docs
```

Then commit and push — GitHub Pages rebuilds `docs/` automatically.

## Notes for contributors

- **Drawing gate** (`src/draw-classifier.ts`): the classifier always returns
  the *closest* letter template, so the check handler also requires
  `isConfidentMatch(score)`. Drawings farther than `MATCH_REJECT_SCORE`
  from every template get a "try again" prompt with no coin change, so a
  dot or scribble can't earn coins. Re-calibrate with
  `bun run calibrate` (`scripts/calibrate.mjs`) if real drawings disagree
  with the threshold.
- **Trophies** (`src/App.tsx` `TROPHIES`, `src/api.ts` `TROPHY_PRICES`):
  prices are the game economy; the shop and trophy case render from the
  same list. The Star Fox Laser (9,999 coins) is intentionally
  near-unachievable.
- **Sound-sort word pool**: "up" is excluded from that game
  (`SOUND_SORT_WORDS`) because the prompt asks for the vowel *in the
  middle*; it remains in the other games.
